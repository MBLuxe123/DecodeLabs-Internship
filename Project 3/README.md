# Project 3: SQL Data Analysis 

## Overview

This folder contains supporting documentation for Project 3: SQL Data Analysis. The project uses SQL to analyze an e-commerce dataset and investigate order patterns, payment methods, product performance, referral sources, order statuses, and coupon-code records.

## Project Resources

The supporting project files are organized into the following folders:

- **SQL Queries:** Contains the SQL script used to retrieve, filter, group, and summarize the dataset.
- **Results:** Contains the Excel workbook with the analysis results.
- **Visualization:** Contains charts created in Excel to present the findings.

## Documentation Purpose

This folder provides supplementary information about the analysis and its deliverables. For the complete project overview, analysis questions, key findings, and conclusions, see the [main Project 3 README](../README.md).

## Tools Used

- Microsoft SQL Server Express
- SQL Server Management Studio (SSMS)
- Microsoft Excel
