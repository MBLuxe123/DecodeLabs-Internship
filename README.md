# DecodeLabs Data Analytics Internship

Welcome to my **DecodeLabs Data Analytics Internship** project repository.

This repository showcases practical data analytics projects completed as part of my internship in the **Data Analytics** domain. The projects demonstrate my experience in data cleaning, data quality validation, exploratory data analysis (EDA), SQL querying, data visualization, dashboard development, and analytical interpretation.

Across these projects, I apply data analytics techniques to structured datasets to assess data quality, investigate patterns, answer business questions, and communicate findings through reports, visualizations, and documented analysis.

## About the Internship

The DecodeLabs Data Analytics Internship provides practical, project-based experience designed to strengthen technical, analytical, and problem-solving skills through real-world data tasks.

Throughout the internship, I apply analytical methods to practical datasets, document my approach, validate results, and present findings in a clear and structured format.

## Projects

### Project 1 — E-Commerce Data Cleaning and Validation

**Tool:** Microsoft Excel

**Objective:** Assess and improve the quality of an e-commerce dataset before analysis.

**Key Activities:**
- Identified and handled missing values.
- Checked for duplicate Order IDs.
- Validated dates, quantities, and unit prices.
- Verified Total Price calculations.
- Conducted data consistency and quality checks.
- Documented cleaning activities, validation checks, and results.

**Deliverables:**
- Excel workbook containing the cleaned dataset.
- Data cleaning log.
- Project README.

### Project 2 — E-Commerce Sales Exploratory Data Analysis (EDA)

**Tool:** Microsoft Excel

**Objective:** Explore e-commerce sales data to understand order patterns, product distribution, payment methods, referral sources, order statuses, and potential outliers.

**Key Activities:**
- Calculated descriptive statistics.
- Analysed product order distribution and yearly order volume.
- Examined payment methods and order statuses.
- Investigated TotalPrice distribution.
- Applied the Interquartile Range (IQR) method to identify potential outliers.
- Created PivotTables and PivotCharts to summarise and compare results.
- Developed an interactive dashboard with KPI cards, charts, and slicers.
- Documented analytical observations and business interpretations.

**Deliverables:**
- Excel workbook containing the sales dataset, analysis report, PivotTables, PivotCharts, and dashboard.
- Dashboard screenshot.
- Exported PivotChart visualizations.
- Screenshot of dashboard slicers.
- Project README.

📂 [View Project 2](./Project%202/)

### Project 3 — E-Commerce Sales Analysis Using SQL

**Tools:** Microsoft SQL Server, SQL Server Management Studio (SSMS), and Microsoft Excel

**Objective:** Analyse e-commerce order data using SQL to answer business questions and identify patterns across products, payment methods, referral sources, order statuses, and coupon-code records.

**Key Activities:**
- Retrieved and filtered data using `SELECT` and `WHERE`.
- Summarised data using `COUNT`, `SUM`, and `AVG`.
- Grouped records using `GROUP BY`.
- Sorted and compared results using `ORDER BY`.
- Analysed order volume and total order value.
- Compared product, payment-method, and referral-source performance.
- Examined order-status and coupon-code distributions.
- Presented selected results through visualizations and documented findings.

**Deliverables:**
- SQL analysis script.
- Cleaned e-commerce dataset used for the analysis.
- Excel workbook containing query results.
- Visualizations of selected findings.
- Project documentation and README files.

The projects demonstrate a progressive data analytics workflow:

1. **Data Preparation:** Inspect, clean, and validate data to identify quality issues.
2. **Exploratory Analysis:** Summarise data, investigate patterns, compare categories, and examine potential outliers.
